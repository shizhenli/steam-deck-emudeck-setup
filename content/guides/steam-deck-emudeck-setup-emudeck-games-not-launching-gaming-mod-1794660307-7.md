You launch a game shortcut in Gaming Mode, but the screen goes black or you are bounced straight back to the home screen. This is a common symptom when **emudeck games not launching gaming mode** occurs, and it usually points to a mismatch between the shortcut and the emulator configuration.

## Check the Shortcut Target

Open the game's properties in Gaming Mode and confirm the target path points to the correct emulator or launcher. A broken or outdated path will cause an immediate return. If the target is wrong, re-run Steam ROM Manager to regenerate the shortcut.

## Verify the ROM File and Emulator

Navigate to the ROM file in Desktop Mode and confirm it exists and is readable. Then launch the same ROM directly from the emulator's desktop interface. If it fails there, the issue is the ROM or emulator, not the shortcut. If it succeeds, the shortcut is the culprit.

## Test with a Known-Good Game

Launch a different game from the same system. If it works, the problem is isolated to the failing shortcut. If it also fails, the emulator itself needs attention. This verification test tells you whether to fix one shortcut or the whole emulator setup.

## Rollback and Recovery

Before making changes, note your current Steam ROM Manager settings. If a regeneration makes things worse, you can revert by restoring the previous shortcut configuration or re-adding the game manually.
